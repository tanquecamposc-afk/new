Sobre los topes de uso
Esta página no te limita: no hay tope de mensajes, ni de largo, ni recortes. Pero de dónde sale el uso sí cambia las cosas.

Abierta en claude.ai consume tu plan de Claude, y ese tope lo pone Anthropic: ninguna página puede levantarlo desde dentro.
Abierta como archivo local con tu clave de API se paga por token y no hay tope diario: gastas lo que uses. Es la vía si el plan se te queda corto.

Para estirar el plan: el nivel Rápido gasta bastante menos que Profundo, y apagar ⚙ Herramientas ahorra las peticiones extra de cada vuelta. Abajo a la izquierda ves lo que llevas gastado hoy.
