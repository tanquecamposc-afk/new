# Cómo pasar la investigación a Google Docs

Archivos:
- `investigacion-planetas-medusa-deporte.html` — documento completo (las 12 imágenes van incrustadas dentro del archivo, no dependen de internet).
- `investigacion-planetas-medusa-deporte.pdf` — la misma versión ya paginada, para revisar o imprimir (10 páginas exactas).

## Opción 1 (la más fiable): importar el HTML a Google Docs
1. Sube `investigacion-planetas-medusa-deporte.html` a Google Drive.
2. Clic derecho sobre el archivo → **Abrir con → Documentos de Google**.
3. Drive lo convierte en un documento editable con las imágenes ya incluidas.

## Opción 2: copiar y pegar
1. Abre el archivo `.html` con Chrome (doble clic).
2. `Ctrl + A` y luego `Ctrl + C`.
3. En un documento nuevo de Google Docs, `Ctrl + V`.

## Después de importar, revisa en Docs
- Márgenes: 2,54 cm (los de por defecto).
- Fuente: Times New Roman 12 e interlineado 1,5 (ya vienen definidos, pero Docs a veces los reajusta).
- Completa los datos de la portada (estudiante, grado y sección, curso, profesor, colegio y fecha).
- Si alguna página queda con una línea suelta, ajusta el tamaño de una imagen para volver a 10 páginas.
