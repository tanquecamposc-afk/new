# Implementar una fase completa
1. Lee `CLAUDE.md`, `docs/PROGRESO.md` y el documento técnico de la fase.
2. Inspecciona el repositorio, identifica componentes reutilizables y prueba baseline.
3. Propón un plan breve con archivos, riesgos y pruebas; no programes el catálogo entero.
4. Implementa un único flujo extremo-a-extremo funcional.
5. Añade unit tests + integración; ejecuta build, pruebas y una demo manual si hay herramientas.
6. Actualiza `docs/PROGRESO.md` con estado REAL, comandos, fallos, commit recomendado.
7. Si hay bloqueo externo, documenta dependencia y entrega la parte comprobable.
